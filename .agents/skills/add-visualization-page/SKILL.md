# Добавление страницы в AI Visual

1. Выбери категорию по теме. Папка первого уровня в `src` задаёт раздел меню. Разборы React идут в `react`, игровые материалы — в `games`. При необходимости сгруппируй новые игровые страницы по игре, например `src/games/aion2/gear-planner/index.html`. Для новой категории укажи понятное название в `CATEGORY_NAMES` в `scripts/build_catalog.py`, если автоматически сформированное название не подходит.
2. Для самостоятельного HTML-файла используй путь вроде `src/react/context-propagation.html`. Для приложения с ресурсами используй отдельную папку с точкой входа `index.html`. В меню появится одна ссылка на эту папку. Имена новых файлов и папок пиши строчной латиницей через дефис. Имена, начинающиеся с точки или подчёркивания, генератор пропускает. При переносе готовой страницы сохрани её интерфейс, поведение и структуру ресурсов.
3. Задай понятное название в `<title>` и краткое описание в `<meta name="description" content="…">` внутри `<head>`. Генератор берёт название и описание нового материала из HTML. Пути к локальным ресурсам указывай относительно страницы.
4. Из корня репозитория запусти `python scripts/build_catalog.py`. Проверь, что в `src/index.html` появилась ссылка в нужной категории. Через локальный HTTP-сервер открой страницу из меню и проверь загрузку ресурсов и основное действие приложения.
5. В ответе укажи путь к странице и результат проверки. Коммит и push выполняй по запросу пользователя. После push в `main` публикацию запускает GitHub Actions.
