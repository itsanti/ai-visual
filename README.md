# AI Visual

Статический каталог самостоятельных приложений. Главная в `src/index.html` оформлена как тёмный указатель по категориям.

## Как добавлять страницы

Папка первого уровня в `src` задаёт категорию. Для одной HTML-страницы достаточно `src/<категория>/<название>.html`. Приложение со своими скриптами и стилями можно положить в отдельную папку с точкой входа `index.html`. В меню появится ссылка на папку. Внутренние HTML-файлы такого приложения в меню не попадут.

Для новых имён файлов и папок используйте строчную латиницу и дефисы. Название ссылки берётся из `<title>`, подпись — из `<meta name="description">`. Названия категорий можно уточнить в `CATEGORY_NAMES` в `scripts/build_catalog.py`. Папки и файлы с начальной точкой или подчёркиванием пропускаются при составлении меню. Например, `src/_assets` подходит для общих ресурсов.

- **Игры** (`games`). При появлении материалов по другим играм группируйте новые страницы по игре, например `games/aion2/gear-planner/index.html`. Для названия ссылки подойдёт формат «Aion 2 — Калькулятор экипировки».
- **React** (`react`). Название файла по теме, например `react/context-propagation.html`, и понятный заголовок вроде «Как обновляется React Context».

## Локальный просмотр

```sh
python scripts/build_catalog.py
python -m http.server 8000 --directory src
```

Откройте [каталог](http://localhost:8000/).

## GitHub Pages

Один раз выберите **GitHub Actions** в **Settings → Pages → Build and deployment → Source**. После отправки изменений в `main` workflow обновит меню и опубликует содержимое `src`. Все ссылки меню относительные, поэтому сайт работает и в подкаталоге репозитория на Pages. [Настройка источника публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
